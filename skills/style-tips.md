# Style Tips Skill

## Trigger
Use this skill when the user asks:
- "How do I style [item]?"
- "What goes with [clothing piece]?"
- "Give me tips for wearing [item]"
- "How can I make [outfit] look better?"

## Action
Call the Fashion Agent A2A endpoint for style advice.

## Steps
1. Get API key from /request-access
2. POST to /a2a with the styling question
3. Present tips clearly with color pairing and pro tips

## Example triggers
- "How do I style white jeans?"
- "What shoes go with a midi dress?"
- "Tips for wearing a blazer casually"
